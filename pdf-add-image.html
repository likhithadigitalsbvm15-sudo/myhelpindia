🖼️ PDF Add Image

Add photos, logos and images to your PDF documents

1. Select PDF

🔒 Your PDF is processed inside your browser. Your file is not uploaded to a server.

2. Select Image

Image Preview


3. Image Settings

⚠️ Adding an image may flatten or affect some advanced PDF features such as interactive forms, annotations and digital signatures.

How It Works

1️⃣ Select your PDF file.

2️⃣ Select a photo or logo.

3️⃣ Choose the page.

4️⃣ Select image position.

5️⃣ Choose image size and opacity.

6️⃣ Click Add Image & Download PDF.

💡 You can use this tool to add a logo, passport photo, stamp image or other pictures to a PDF.
